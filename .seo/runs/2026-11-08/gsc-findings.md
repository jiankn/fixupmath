# FixUpMath：GSC 与 Cloudflare 交叉诊断

日期：2026-11-08（北京时间）。本轮是 API 只读取数、抓取与索引排查，加低风险页面优化。没有修改 Cloudflare 安全配置，没有推送或部署。

## 核心发现

**站点曾发生真实的 Googlebot 抓取拦截；当前访问已有恢复，但索引与搜索曝光尚未恢复。** 不能继续只用“权重不足”“字数偏少”解释现状。

- Cloudflare 安全事件查询在 2026-10-24～11-08 的时间范围内返回了 **50 条 block 样本**，来自 Google ASN **15169**、Googlebot UA，涉及 **30 个不同路径**，同属托管规则 `8fcb869e55804a6d94f482a0a25aa53a`。这是查询返回的样本数，不宣称全部请求总量。
- 样本中最早事件是 10-24 12:54:37 UTC，最后一条是 10-31 12:03:53 UTC（北京时间分别为 10-24 20:54:37、10-31 20:03:53）。首页、`sitemap-index.xml`、`sitemap-0.xml` 和多张计算器页都被拦过。
- BTU 页的 10-29 09:58:49 UTC、电压降页的 10-29 12:25:48 UTC，Cloudflare 拦截时间分别与 GSC 的 `lastCrawlTime` **完全相同**。首页 10-31 07:57:17 UTC 的拦截也与旧 GSC 检查对应。
- 这组交叉证据确认了实际 Google 抓取遭拦截。它能解释抓取/收录困难，但不能证明全部未收录都由这一条规则造成。

账号审计记录显示，11-02 13:55:33 UTC（北京时间 21:55:33）曾更新 `http_request_sbfm` 阶段规则。旧规则具体表达式/可读名称未取到，不把它臆测为某个 AI 开关，也不把这次规则更新等同于完整的旧值→新值证明。

GSC 本次检查中，有 **19 个 URL** 在该时间之后已被 Google 成功抓取，包括首页、混凝土三页、conduit、面积、地毯、壁纸和 wire-size 页。当前公开访问抽查共 12 次全部 HTTP 200、无挑战标记；更换 UA 不会模拟真实 Google 来源，所以只把它当兼容性检查。

因此本轮没有再关闭安全功能或添加宽泛放行。后续如重新出现拦截，应按真实 Google 来源、命中规则和时间核实，再做局部修正。

## 搜索表现

GSC 搜索类型为 Web，`dataState=final`。GSC 日报以太平洋时间计日，不等同于北京时间自然日。

| 指标 | 请求窗口 2026-10-09～11-05 | 前一窗口 2026-09-11～10-08 |
|---|---:|---:|
| 点击 | 2 | 0 |
| 曝光 | 5,160 | 552 |
| CTR | 0.0388% | 0% |
| 平均排名 | 55.60 | 51.43 |

本次实际返回的最近日报截至 **11-04**，11-05 缺少日报，不补零。两个窗口上线天数、有效曝光天数、查询构成不同，不能把曝光增长直接解释成某次优化的收益。

10-28 起曝光几乎归零，11-03、11-04 各只有 1 次曝光。历史窗口合计数掩盖了这个中途断崖，应先看日报和索引恢复，而非仅看累计增长。

API 返回了 1,175 条 query 记录、1,177 条 query-page 记录、35 个有表现的页面。匿名查询和数据截断意味着它们仍不是全部关键词，但足以推翻“网站总共只有 15 个词、没有真实点击”的说法。美国占 4,183 次曝光，约 81.1%，本轮没有扩多语言的证据。

## 本轮落地与前三个改善候选

1. **面积计算器**：712 次历史曝光，平均 40.65；主查询之一 78 次曝光、平均 24.82。补了英尺/英寸误输入、不重叠分区合计及净面积→购物数量的说明与相关内链。
2. **地毯计算器**：701 次历史曝光，平均 42.73；有测量、平方英尺/平方码的真实查询，部分平方码同义查询曾在 10～15 名。补量房步骤、单位区别、卷宽限制与切割计划的差异。
3. **壁纸计算器**：257 次历史曝光，平均 38.25；pattern repeat 查询有表现。补 8/9 ft 墙高的对花算例、物理卷/标价单位与门窗扣除假设。

同时精简六页 metadata，共享模板补了品牌分享图。没有按词数扩写，没有为同义词建新页，没有改变混凝土三页分工。slab/bag 两页在当前历史窗口没有查询记录，不能据此判断与主页发生内耗。

tile 页部分靠前查询实际是数学作业题，不把它们当作装修用户需求；voltage-drop 的优先事项是历史 403 的复核，不能只依据第三方检测到的词数排序。

## 外部引用现状

只读核对了用户原有 `reports/backlink-plan/backlinks.csv`：20 行，4 个 submitted、16 个 sent，没有填入任何 `live_url`。这些只能计作提交/联系记录，**不能计作 20 条已获得外链**。没有修改原台账或重发邮件。

下一步外链工作应先补可公开验证的实际页面和链接属性，再对照相关落地页；本轮没有已验证外链数量可以拿来证明“权重足够”或“完全没有外链”。

## 后续验证

- 发布本轮修改后，在 GSC 对 BTU、电压降与三张重点页做实时网址测试，并按需要请求重新编入索引。只读 API 不能替代这个 UI 功能。
- 在正常访问前提下，观察 Google 是否重新抓取、44 个已抓取未收录页是否转为收录，以及曝光是否连续恢复；13 个未知 URL 同时检查首次发现情况。
- 建议 7～14 天后拉同口径快照。恢复前不批量改 URL、删页或加页，也不为短期波动不断重写 Title。
- 所有原始 GSC/Cloudflare 数据放在本轮 `source/`，已加入 Git 忽略；对外报告不包含 OAuth 凭据或访客 IP。
